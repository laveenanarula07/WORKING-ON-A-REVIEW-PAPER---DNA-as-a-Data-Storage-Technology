# WORKING-ON-A-REVIEW-PAPER---DNA-as-a-Data-Storage-Technology
Currently developing a scientific review paper investigating DNA as a next-generation digital data storage medium. This project explores how conventional binary data (0s and 1s) can be encoded into the four nucleotide bases of DNA—adenine (A), thymine (T), cytosine (C), and guanine (G)—through binary-to-DNA mapping algorithms.
